# 💊 Pharmacy Management System

A Pharmacy Management System built with **Django** to help pharmacies efficiently manage medicines, inventory, sales, customers, suppliers, and billing. The system simplifies daily operations through an easy-to-use web interface.

---

## 📌 Features

- 🔐 User Authentication (Admin & Staff)
- 💊 Medicine Management
- 📦 Inventory Management
- 🏢 Supplier Management
- 👥 Customer Management
- 🛒 Sales & Billing
- 📋 Purchase Management
- 📊 Dashboard with Statistics
- 🔍 Search & Filter Medicines
- ⚠️ Low Stock Alerts
- 🧾 Invoice Generation

---

## 🛠️ Tech Stack

- Backend: Django (Python)
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Database: SQLite (Development) / PostgreSQL (Production)
- Version Control: Git & GitHub

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/pharmacy-management-system.git
```

### Navigate to the project folder

```bash
cd pharmacy-management-system
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Apply migrations

```bash
python manage.py migrate
```

### Create a superuser

```bash
python manage.py createsuperuser
```

### Run the development server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
